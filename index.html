Welcome to AI Council 👋

AI Council asks several AI models at once and combines their best answers. To use it you need your own free API key — think of it as a password that lets this page talk to an AI service for you. It takes about 2 minutes and no credit card.

2

Copy your key

On the provider's page, click Create API key, then copy the long code it shows you. It usually starts with letters like gsk_ or AIza.

3

Paste it here

Your key stays private. It's saved only in this browser and is sent only to the AI service you got it from — never to us. Free plans have usage limits, so if one service says "rate limited", wait a minute or add a second key.

🧠 Working memory

After each exchange, a fast model quietly extracts lasting facts and keeps a rolling summary of older conversation. Both are fed to every model on every question. Facts are saved in your browser (when opened as a local file), so they survive closing the page.

Provider API keys

If you set a PROXY_TOKEN secret when you deployed your Worker, paste that same value into the 🔒 proxy card below once per browser — otherwise leave it blank. Any key you type directly into a provider card below is used instead of the built-in proxy for that provider, and stays in this browser only if you tick "Remember this key".
